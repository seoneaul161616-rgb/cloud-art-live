# 손으로 빚는 구름 (배포용)

iPad 전면 카메라로 손모양(○ △ □)을 인식해 3D 복셀 구름을 바꾸는 미디어아트의 **빌드 결과물**입니다.
GitHub Pages 로 공개되는 정적 사이트이며, 소스 코드는 비공개 저장소 `cowave-web` 에 있습니다
(`npm run build:live` 로 이 폴더 내용을 다시 만들 수 있습니다).

- ○ 동그라미: 뭉게구름 · △ 세모: 먹구름과 비 · □ 네모: 옅게 넓게 퍼지는 구름
- iPad Safari 에서 열고 공유 → "홈 화면에 추가" 하면 전체화면 앱처럼 실행됩니다.
